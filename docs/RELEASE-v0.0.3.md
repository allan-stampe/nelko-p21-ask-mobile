NELKO P21 – ASK Mobile Edition v0.0.3

Removes the yellow experimental warning box at the top of the app and updates the version to 0.0.3 (Android versionCode 3).

Bluetooth Classic SPP, printer commands/bitmap generation, text editing/preview, diagnostics and the remaining interface are unchanged from v0.0.2. The Android app icon is unchanged. No Windows project changes.

Download the Android APK directly (Android 8+, no Play Store). SHA256SUMS.txt and APK-CERTIFICATE.txt identify the file and public signer. These builds retain temporary CI test signing keys: uninstalling an older version may be required before installation and deletes saved preferences. Export needed logs first, then select/reconnect the printer again.

Existing physical-test limits from v0.0.2 remain; this UI-only update does not claim additional printer validation. Offline operation, no cloud/account/ads/telemetry, MIT credits and the bundled Go font license are preserved.
