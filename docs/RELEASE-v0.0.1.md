Experimental first Android build of NELKO P21 – ASK Mobile Edition.

**Android Bluetooth communication and printing are NOT yet verified on physical hardware.** Please use this release for the owner's hardware testing; automated fake-transport tests do not establish printer compatibility.

Includes Bluetooth Classic SPP discovery/connection, foreground reconnect, Danish/English, battery query, Cancel Pause, the byte-exact Windows-reference test print, and timestamped ASCII/HEX log export. No advanced designer, BLE or iOS implementation yet. No account, cloud, ads, subscription, telemetry or runtime Internet permission.

Download the APK directly and allow installation from your browser/file manager (Android 8+). Verify SHA256SUMS.txt. This experimental APK uses a temporary Android test signing key; future builds can require uninstalling the old version and losing saved preferences. Export needed logs first. APK-CERTIFICATE.txt identifies this artifact's public signer.

See the README and docs/HARDWARE-TEST.md before testing. The ZIP includes protocol, decisions, license and credit documentation. Windows v1.0.1 remains unchanged.
